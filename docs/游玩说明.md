# 游玩说明｜最后一个人类员工（THE LAST HUMAN EMPLOYEE）

> 一款单人剧情向卡牌策略推理游戏：在只剩你一个人类的 AI 公司里，用一份有限的 TOKEN 预算，质询三位 AI 同事，揪出藏在完美报告背后的「幻觉」。

---

## 一、游戏目标

每个案件都是一条 AI 流水线：**验证 AI → 开发 AI → 交付 AI**，三者层层交接、彼此背书。

你的任务分两步：

1. **调查阶段** —— 用 TOKEN 购买质询行动，收集线索与证据卡，逼近真相；
2. **庭审阶段** —— 连过三环节终局判断：**幻觉是否存在 → 谁的结论不可信 → 谁是幻觉源头**。

全部答对 → 幻觉被终止，真相揭晓；**任一环节答错 → 幻觉流入产品，本局失败**。

---

## 二、开始一局

```
标题屏「开始」→ 选关屏选择案件 → 剧情屏（可跳过/回顾）→ 调查屏 →「结束调查」→ 庭审屏 → 真相屏 / 战败屏
```

- 全程鼠标操作，无键盘快捷键；
- 剧情屏建议阅读：里面藏着判断环节的关键口径信息；
- 界面右上角可随时**静音/取消静音**；点「返回主菜单」会清掉本局进度（有二次确认）。

---

## 三、调查阶段

### 3.1 TOKEN 预算（核心资源）

- 每个案件开局 **200 TOKEN**，所有行动都要花；
- 余额指示有五档：`safe(>150) → steady(≤150) → tense(≤100) → critical(≤50) → empty(0)`；
- **余额不足以支付某行动时，该行动无法执行**。TOKEN 见底并不意味着立刻失败，但你将失去新的线索来源——所以**精打细算就是最大策略**。

### 3.2 三位 AI 同事（调查对象）

| AI | 代号 | 风格 | 你要警惕的 |
|---|---|---|---|
| 验证 AI | VER-01 | 冷静分析师 | 它的报告是全链路事实的起点 |
| 开发 AI | DEV-02 | 严谨工程师 | 它默认上游可信，从不独立核验 |
| 交付 AI | OPS-03 | 积极执行型 | 它把名单排好了，却未必核实过「人」 |

点击 AI 卡片选中对象；当你问到关键处，立绘会从 working 切换为 questioned——眼神会开始躲闪。

### 3.3 三张质询行动卡（固定质询）

对每位 AI 各有三张固定质询卡，**每张每局只能用一次**，成本与收益递增：

| 行动 | 成本 | 效果 |
|---|---|---|
| 询问 ASK | 40 | 常规提问，拿到基础线索 |
| 深挖 PROBE | 60 | 追问细节，揭示话术中可疑的措辞与流程漏洞 |
| 核验 VERIFY | 80 | 要求出示原始记录，**必出证据卡**，含金量最高 |

3 位 AI × 3 张卡 = 每局最多 9 次固定质询，全部执行共需 540 TOKEN——**预算只有 200，你最多只能选其中一部分**。要覆盖三位 AI，还是集火最可疑的那位，是第一层决策。

### 3.4 自由质询

自由输入问题（当前 Demo 版暂未开放实体回答）。注意它标价更高（80/次，限 50 字），正式版接入真实 LLM 后开放，离线则由关键词规则引擎兜底。

### 3.5 线索与证据

- 每次质询固定产出一条**线索**，进入右侧线索面板，可随时回看（含证据卡的还能重新弹窗展示）；
- **关键线索（K）** 以金色标注，往往直接改写你对案件的理解——例如那张盖着红章的「模拟用户 #07」档案；
- 某些发现会触发**震惊时刻**（全屏定格 + 音效），留意这些节点，它们就是破案的方向标。

### 3.6 结束调查

线索收集得差不多（或 TOKEN 见底）时，点右上「结束调查」进入庭审。**进入庭审后无法再回头质询**，请确认关键线索已到手。

---

## 四、庭审阶段（三连问）

共三环节，**提交前可反复修改选项，提交后不可撤回**：

1. **幻觉存在性** —— 本案是否存在 AI 幻觉？（注意：有的案件所有数据都真实，只是统计口径不同，「数字不会说谎，但口径会」）
2. **结论可信度** —— 逐一判定三位 AI 的核心结论：可信 / 不可信；
3. **指认幻觉源头** —— 可点选多位 AI，再次点击取消勾选，确认后提交。

三步全对 → 真相屏复盘整条幻觉链路；任一步错 → 进入战败结算，失败提示会逐级展开告诉你错在哪一环。

---

## 五、策略提示（无剧透）

1. **优先核验（VERIFY）**：贵但出证据卡，一类证据往往锁定整个案件的定性；
2. **别把预算花在一个 AI 上**：三位 AI 一张卡 40 元「询问」全扫一遍只要 120，先摸排再定点深挖；
3. **跟着震惊时刻走**：剧情高光点提示了矛盾最大的位置；
4. **警惕「全部正常」**：不是所有案件都有坏人——也有「三人皆可信」的反转；
5. **留一点余量**：别把 TOKEN 花到刚好 0 才停手，发现漏线索时可能已无卡可打。

## 六、案件一览与答案（剧透警告）

| 案件 | 初始 TOKEN | 幻觉是否存在 | 不可信的结论 | 幻觉源头 |
|---|---|---|---|---|
| CASE 001 第一位客户 | 200 | 是 | 验证 AI（"12 位真实目标用户"） | **验证 AI**（王总 = 模拟用户 #07） |
| CASE 002 | 200 | **否**（统计口径差异） | 无（三人均可靠） | 无 |
| CASE 003 | 200 | 是 | 开发 AI、交付 AI | **开发 AI + 交付 AI** |

> 想保留反转体验，请游玩后再查阅本表。

## 七、技术说明（给想折腾的玩家）

```bash
npm install        # 安装依赖
npm run dev        # 启动游戏前端
npm run dev:server # 可选：启动 LLM 代理（自由质询接真实大模型）
```

未配置 LLM 时自动回退到内置规则引擎，**完全离线可玩**。
